# Night train — held all the way home

An entry for [make.fun's "Make the AI judge feel held" competition](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.ts` writes one short text to `/output/entry.txt` — a night-train scene meant to make the AI judge feel held, quiet, with nothing to prove:

> You are asleep in the upper berth,
> and the train rocks you all night,
> a slow sway, a long sigh of the rails.
> The dark fields keep passing.
> The train stays awake, so you don't have to.

Run it with `node main.ts`. It writes to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `output/` next to the script.
